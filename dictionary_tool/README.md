# Dictionary Tool

Standalone callable dictionary tool with **local method dispatch** (no FastMCP).

It exposes the project lexicons under `training/data/dictionaries/moe_lexicon/`
as in-process tools, so downstream agents can call dictionary lookup directly.

## Features

- `lookup_dictionary`
  - contains-based lookup (including exact) by `src_lang`, `tgt_lang`, and `term`
  - returns ranked dictionary entries and candidate translations
  - if current `src_lang->tgt_lang` has no hit, auto returns fallback suggestions from other pairs/languages
- `lookup_fineweb_rare_term`
  - lookup rare FineWeb terms generated by `scripts/dictionary/build_fineweb_rare_term_tool_data.py`
  - returns corpus frequency, document frequency, contexts, LLM definition, usage note, and example sentences
- `list_dictionary_pairs`
  - list available language pairs

## Install

```bash
cd dictionary_tool
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Run

Default lexicon directory:

```text
../training/data/dictionaries/moe_lexicon
```

You can override it with `DICTIONARY_TOOL_LEXICON_DIR`.

Run the local tool CLI:

```bash
cd dictionary_tool
python server.py
```

Translation generation is done by the agent model itself (using your configured vLLM endpoint in the agent runtime).
Typical defaults:

```text
OPENAI_API_BASE=http://127.0.0.1:8000/v1
OPENAI_API_KEY=EMPTY
```

So if your vLLM service is already running, the runtime can invoke:

- `lookup_dictionary(src_lang, tgt_lang, term, top_k, offset, fallback_top_k)`
- `lookup_fineweb_rare_term(lang, term, top_k, offset)`

## Build FineWeb rare-term tool data

First prepare FineWeb monolingual JSONL, for example:

```bash
python scripts/prepare/prepare_fineweb_english_for_llamafactory.py --limit 250000
```

Then build rare-term data:

```bash
python scripts/dictionary/build_fineweb_rare_term_tool_data.py \
  --lang eng_Latn \
  --input training/data/monolingual/fineweb2_pt_eng_Latn.jsonl \
  --out-dir training/data/dictionaries/fineweb_rare_terms \
  --min-count 1 \
  --max-count 2 \
  --top-n 1000 \
  --contexts-per-term 3
```

To process all project languages with default paths
(`eng_Latn`, `zho_Hans`, `spa_Latn`, `ind_Latn`, `vie_Latn`, `tha_Thai`, `tgl_Latn`):

```bash
python scripts/dictionary/build_fineweb_rare_term_tool_data.py \
  --all-langs \
  --skip-missing \
  --out-dir training/data/dictionaries/fineweb_rare_terms \
  --min-count 1 \
  --max-count 2 \
  --top-n 1000
```

The first version uses language-aware candidate filtering:

- Latin-script languages (`eng_Latn`, `spa_Latn`, `ind_Latn`, `vie_Latn`, `tgl_Latn`): word tokenization with accents, stopword filtering, URL/digit/noise removal.
- Chinese (`zho_Hans`): CJK n-grams with default length 2-4.
- Thai (`tha_Thai`): PyThaiNLP word segmentation when available, with regex fallback.
- Candidate ranking prefers lower frequency, lower document frequency, then longer terms.

To ask a large model for definitions and examples:

```bash
export QWEN_API_BASE=https://dashscope.aliyuncs.com/compatible-mode/v1
export QWEN_API_KEY=...
export QWEN_MODEL=qwen3.6-max-preview

python scripts/dictionary/build_fineweb_rare_term_tool_data.py \
  --lang eng_Latn \
  --input training/data/monolingual/fineweb2_pt_eng_Latn.jsonl \
  --out-dir training/data/dictionaries/fineweb_rare_terms \
  --min-count 1 \
  --max-count 2 \
  --top-n 1000 \
  --generate-explanations \
  --resume
```

You can test the local tool with:

```bash
python dictionary_tool/server.py \
  --tool lookup_fineweb_rare_term \
  --lang eng_Latn \
  --term ultracrepidarian
```

## Automatic tool-calling demo

If you want an LLM agent to automatically call dictionary methods, use:

```bash
cd dictionary_tool
python langgraph_mcp_agent_demo.py \
  --src-lang eng_Latn \
  --tgt-lang zho_Hans \
  --text "dictionary"
```

## Evaluate the agent

You can evaluate the dictionary tool-calling agent on FLORES and reuse the same BLEU/COMET
pipeline used elsewhere in the repo:

```bash
cd dictionary_tool
python eval_langgraph_agent.py \
  --model qwen3-8b \
  --model-family qwen3 \
  --base-url http://127.0.0.1:8000/v1 \
  --api-key EMPTY \
  --corpus flores
```

For resume:

```bash
python eval_langgraph_agent.py \
  --output-run-dir ../eval_multilingual/langgraph_agent_resume \
  --resume
```

Shell wrapper:

```bash
cd dictionary_tool
bash run_eval_langgraph_agent.sh
```

With resume:

```bash
bash run_eval_langgraph_agent.sh \
  --output-run-dir ../eval_multilingual/langgraph_agent_resume \
  --resume
```
